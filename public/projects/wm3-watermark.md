# wm3 盲浮水印外流溯源系統（algorithm_V3）

## 概述

發佈圖片時，把每位使用者專屬的識別碼悄悄寫進圖片亮度（肉眼看不出來）；之後若圖片外流，即使經過重新壓縮、截圖、縮放或裁切，仍可用**金鑰**與**名冊**指認是哪一份外流。設計原則是**證據不足時寧可回報「無法溯源」，也不指認錯人**。

## 資料流

```
寫入：原圖 + 使用者 ID + 金鑰 → 亮度 → Haar LL → 4×4 區塊最大奇異值 → QIM 量化 → 專屬圖片 (JPEG Q95)
追查：外流圖 (+ 原圖) + 金鑰 + 名冊 → 對齊 → 加權投票 → Reed-Solomon 解碼 → 統計檢定 → 指認 / 疑似串謀 / 無法溯源
```

## 兩種追查模式

| | informed（有原圖） | blind（沒有原圖） |
|---|---|---|
| 做法 | 先把外流圖對齊回原圖座標，再累積證據對名冊做統計檢定 | 直接重算分析、加權投票後用 Reed-Solomon 解出碼字 |
| 能處理 | 壓縮、雜訊、模糊、調色、縮放、裁切、旋轉、翻轉、截圖 | 壓縮、雜訊、模糊、亮度平移 |
| 20 張照片 × 31 種攻擊 | **615 / 620（99%）** | 254 / 620（41%，幾何攻擊原理上無法處理） |

## 核心技術

- **隱形**：只改亮度的微小位移，預設組 PSNR 約 42–43 dB
- **耐壓縮**：每區塊 1 位元、每位元至少重複 24 次、金鑰置換散佈全圖、Reed-Solomon 糾錯、加權投票
- **不誤抓**：金鑰標籤、名冊精確比對、Bonferroni 統計檢定等多道獨立防線
- **效能重構**：以數學等價的 rank-one 更新取代完整 DWT / SVD 重建；33 MP 寫入鏈由 V2 的 6818 ms 降到純 CPU（Numba）106 ms，GPU（CuPy）再降到 28 ms，無 GPU 時自動退回 CPU
- **相簿抽樣服務**：一本相簿只替約 10% 的圖寫入，背景佇列批次處理
- **與 V2 雙向相容**：V2 寫的圖 V3 讀得到，反之亦然

## 操作介面

- **wm3 工作台**：寫入與解碼分開，支援批次、排程與歷史紀錄（FastAPI + Vue 3 + Element Plus）
- 命令列 `python -m wm3.cli` 與 Python API
- 專案內含可攜式 Python 3.12、離線 wheelhouse 與一鍵啟動腳本，服務只綁 `127.0.0.1`
- 後端附自動化測試（工作台 33 個測試，使用合成影像）
