# AI Guard 企業生成式 AI 資料防護

## 概述

企業生成式 AI 資料防護系統的可執行原型（MVP）：在員工把內容送進 AI 網站之前，於瀏覽器本機檢查是否含有敏感資料，並依企業政策**允許、提醒、遮罩後送出或阻擋**。包含本機政策／事件服務、瀏覽器管理主控台，以及 Chrome／Edge Manifest V3 擴充功能。

## 資料流

```
員工貼上 / 送出 / 上傳檔案 → 擴充功能本機偵測 → 依政策處置（允許 / 提醒 / 遮罩 / 阻擋）→ 事件中繼資料 → 本機主控台
```

## 核心功能

- 支援 ChatGPT、Claude、Gemini、Microsoft Copilot：攔截貼上文字、送出按鈕、Enter 送出、表單送出、檔案選取與拖放
- 偵測規則：電子郵件、電話號碼、通過 **Luhn 驗證**的卡號、常見 API 金鑰／私鑰標記，以及企業自訂關鍵字
- 純文字檔檢查（`.txt` `.csv` `.json` `.md` `.log` `.yaml` `.xml` `.html`，單檔上限 2 MiB）
- 遮罩替換在瀏覽器本機完成；「觀察」與「執行」兩種模式，可先校準規則再正式攔截
- 管理主控台可設定受管理 AI 網站、資料處置、未知帳號與無法檢查檔案的處置、事件保存天數

## 隱私設計

- 事件只記錄時間、網站網域、命中分類數量、處置結果與政策版本，**不保存提示原文或命中的值**
- 政策服務固定綁定 `127.0.0.1`，不提供網路介面；不需安裝任何 npm 套件

## 已知限制（原型階段）

依網站 DOM 攔截，網站改版或直接呼叫網路 API 可能繞過；尚未提供 SSO、RBAC、TLS 與 SIEM 整合，Office／PDF／圖片檔不解析。

## 技術棧

JavaScript · Chrome / Edge Extension (Manifest V3) · Node.js 20（零相依 HTTP 服務）· DLP 規則引擎
