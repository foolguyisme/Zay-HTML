# LaptopSentinel 個人筆電入侵監測系統

## 概述

常駐在個人筆電的本機監測工具：讀取 Microsoft Defender 事件、Windows Security Center 防毒健康狀態、IPv4／IPv6 TCP 連線與常見自動啟動位置，依證據產生警示，並用白話告訴使用者「發生什麼、為什麼值得注意、可能是正常的原因、下一步」。

設計原則是**本機優先、離線可用、以證據解釋警示**：它協助及早發現與調查異常，不宣稱電腦絕對安全，也不取代防毒軟體。程式**不會自動刪除檔案、封鎖 IP 或上傳監測資料**。

## 資料流

```
Defender 事件 / 防毒健康 / TCP 連線 / 自動啟動項目 / 檔案簽章
        → 收集器 → 規則與關聯判斷 → 警示（嚴重度與可信度分開）→ 桌面介面 / 托盤通知
```

## 核心功能

- **一眼看懂的首頁**：用一句話說明現況，並列出防毒、防竄改、病毒碼、防火牆、最近更新等保護健康項目
- **白話警示卡**：每則警示分四段說明；可標記「我認得這個」、「稍後提醒」或「我處理好了」，之後能撤銷
- **自動啟動項目總覽**：列出所有開機或登入時會執行的項目，依簽章與位置分組，並驗證新增或變更項目的檔案簽章
- **高訊號、低雜訊的偵測**：
  - 第一次連網的新程式（前 7 天只學習、不發警示）
  - hosts 檔、代理、DNS 被改動，以及從另一台電腦遠端桌面登入
  - 簽章有效的 PowerShell、mshta、rundll32 被用於編碼指令、從網址載入等可疑用法
  - 直接讀取 Defender 的偵測清單，掌握威脅被隔離、移除或仍在執行
- **多訊號關聯**：例如可疑自啟加上同程序的外部連線，會自動升級警示
- **托盤常駐**：關閉視窗後縮到右下角繼續監測，可開機自動啟動或勿擾 24 小時

## 輕量化

- 托盤原生介面取代 Windows Forms，縮在托盤時私有工作集約 5 MB
- 發行檔：精簡版（桌面加命令列）僅約 4.4 MiB；自包含版約 136 MiB，不需另裝 .NET
- 掃描節奏隨情況調整：接電源 30 秒、使用電池或螢幕鎖定 60 秒
- 資料庫最多保留 30 天，檔案超過 500 MB 時自動縮短保留並壓縮

## 品質

- 450 個自動測試、12 個命令列正面與負面測試皆通過
- 用標準 EICAR 測試檔做過真實的 Defender 偵測驗證，並因此找出並修正三個缺陷
- 依賴套件經 `dotnet list package --vulnerable` 查核

## 已知限制

目前為開發預覽版，尚未安裝成 Windows Service；Windows 11 實機驗收、14 天誤報觀察與 24 小時效能測試尚未完成。
